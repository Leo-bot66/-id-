提示「Apple ID 或密码不正确」怎么办？

这是共享账号最常见的一条报错，也是被误解最多的一条：九成以上的情况不是账号废了，而是你手上的密码已经过期。处理起来通常只要一分钟。

一、这条报错的完整样子

Apple ID 或密码不正确。
请检查你的 Apple ID 和密码，然后重试。

出现位置一般在【App Store】右上角头像的登录框，或在下载应用弹出验证时。

二、真正的原因：密码轮换

共享账号不可能把密码固定下来——一旦固定，几天内就会被公开到各种网站、论坛与聚合页上，随后被大量陌生设备登录，Apple 判定异常并锁定。所以这类账号的通行做法是由系统定期轮换密码。

轮换发生时：

  • 新密码立即生效；
  • 旧密码当场失效——这就是你看到「密码不正确」的原因；
  • 账号本身依旧是可用的，只是需要取新密码。

三、正确解决顺序（按这个来，一分钟内解决）

  1. 取当前密码。回到账号列表页，找到你正在用的那个账号，点「显示密码」复制此刻显示的密码。不要使用收藏夹、聊天记录、笔记里保存的旧密码。
  2. 完整退出再重新登录。【App Store】→ 右上角头像 → 滑到底部「退出登录」，然后重新输入账号密码。带着旧凭据直接改密码容易触发缓存问题。
  3. 仍然失败就换号。若列表页显示密码但登录仍报错，说明该账号已被轮换到你看不到的状态，直接换下一个账号，不要纠缠。
✅ 判断标准

同一个账号最多试两次。两次都进不去，一律换号。换号的成功率远高于反复重试。

四、绝对不要做的事

⚠️ 反复重试会毁掉账号
  • 不要连续试错。短时间多次输错会触发 Apple 安全锁定，把「暂时不可用」变成「彻底不可用」，还会连累后面的使用者。
  • 不要点「忘记密码 / 找回账号」。这是共享账号，验证码会发往账号持有者的设备，你走不通这条流程，反而可能触发额外风控。
  • 不要把密码改掉。改动会让所有使用者（包括你自己后续）都无法登录。

六、为什么总是遇到这条报错

共享账号的本质是「一个账号被大量陌生用户轮流登录」，密码轮换就是对抗这种滥用而存在的机制。所以「密码不正确」出现的频率与账号池健康度直接相关，你无法从客户端侧降低它。若你希望打开就能用、不用反复取密，应改用独享账号。
