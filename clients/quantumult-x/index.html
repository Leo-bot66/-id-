Quantumult X 下载与共享账号使用指南

Quantumult X（俗称圈 X）是 iOS 上另一款主流代理客户端。它比小火箭强，也比小火箭难。在折腾之前，先确认你真的需要它。

一、先想清楚：你需要 Quantumult X 吗

对比项Shadowrocket（小火箭）Quantumult X
上手难度低，导入订阅即可用较高，规则、策略组、脚本都需要手动理解
分流规则能力够用更强，支持更细的策略与重写
脚本 / 自动化有限体系完整

结论：如果你只是要「能连、能上」，装小火箭就够了。Quantumult X 的价值只有在复杂分流和脚本需求下才体现得出来，否则你会花大量时间在配置上而不是使用上。

二、为什么必须用外区 Apple ID

  • Quantumult X 是付费应用，且已从中国区 App Store 下架，中国区账号连搜索都搜不到。
  • 付费应用不能靠「登录一下就白拿」——必须该账号此前购买过，才能在「已购项目」中重复下载。

共享账号正是利用这一点：账号持有者已付过费，你把账号登录到 App Store 后，「已购项目」里就带上了 Quantumult X。

三、用共享账号下载的正确流程

  1. 【App Store】→ 右上角头像 → 滑到底部「退出登录」，先清掉自己的账号。
  2. 在同一位置登录共享 Apple ID。（只在这里登录，不要进「设置 → iCloud」——那是唯一会造成真实损失的误操作。）
  3. 回到头像 → 「已购项目」，在顶部搜索框输入 Quantumult X。
  4. 找到后点击云朵下载图标下载。（不要在商店搜索页点价格按钮，那会走购买流程。）
  5. 下载完成后立即【App Store → 头像 → 退出登录】，换回你自己的 Apple ID。已下载的应用仍然保留。
⚠️ 认准正版，别下仿冒

App Store 里存在名称近似的山寨客户端。下载前点开详情，核对开发者名称、评分数量与更新记录。

四、下载完打不开 / 连不上？

这与账号无关。Quantumult X 只是工具外壳，本身不含任何节点。你需要：

  1. 从服务商处取得订阅地址；
  2. 在客户端内找到「订阅 / 节点」相关页面，粘贴地址并拉取；
  3. 拉取成功后选择一个节点，开启代理开关。

若拉取失败：先确认订阅是否过期、节点是否在线，再排查网络环境。若「已购项目」里搜不到应用，则是账号问题——换账号。

✅ 一句话区分

搜不到 / 下不了 → 账号问题；下好了连不上 → 节点或订阅问题。

五、常见问题

登录后提示「此 Apple ID 尚未在 App Store 使用过」

属正常首次提示，点「检查」→ 同意条款与条件 → 继续；若要求填写付款方式，选择「无」。

提示「需要验证」「双重认证」

该账号已进入 Apple 安全验证状态，验证码发往账号持有者，你无法获取。直接换号。

下载后要求内购解锁

正版 Quantumult X 为一次性付费购买，若应用内再要求额外付费解锁核心功能，需警惕是否为仿冒应用，请核对开发者信息。
