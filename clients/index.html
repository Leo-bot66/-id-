二、为什么它们都需要外区 Apple ID

这类代理客户端在中国区 App Store 已经下架，直接用中国区账号搜不到。要下载就必须满足两个条件：

  1. 使用非中国区的 Apple ID（美区、港区、台区等）；
  2. 该 Apple ID 曾经购买过这个应用——付费应用不能靠「登录一下就白拿」，必须是购买记录持有者才能重复下载。

共享账号的原理正是第 2 条：账号持有者已经付过费，你把账号登录到 App Store，「已购项目」里就会带上这些应用。

三、通用下载流程（所有客户端通用）

  1. 打开【App Store】→ 右上角头像 → 滑到底部「退出登录」，先清掉自己的账号。
  2. 在同一位置登录共享 Apple ID（只在这里登录，不要进「设置 → iCloud」）。
  3. 若提示「此 Apple ID 尚未在 App Store 使用过」，点「检查」并同意条款，属正常首次提示。
  4. 搜索目标客户端名称并下载；若搜不到，进「已购项目」里搜索应用名下载。
  5. 下载完成后立即回【App Store】退出登录，换回你自己的 Apple ID。
⚠️ 认准正版，别下仿冒应用

App Store 存在大量名称相似的山寨应用。下载前请点开应用详情，核对开发者名称、评分数量、更新记录与截图；价格明显异常、评论稀少的，一律不装。

四、下载完打不开 / 连不上？

这是最常见的误解。这些客户端只是工具外壳，本身不含任何节点。你必须先从服务商处取得订阅地址，再导入客户端，才有可用节点。

  • Shadowrocket：首页右上角「+」→ 选择「订阅」→ 粘贴订阅地址 → 更新。
  • Quantumult X / Stash / Loon：一般在「订阅 / 节点」页粘贴订阅地址后拉取。
  • 导入后若依旧不通，先确认订阅是否过期、节点是否在线，再排查网络环境。
