❓ 五类常见报错与处理

1. 提示「此 Apple ID 尚未在 App Store 使用过」

这是首次登录的正常提示，不是账号问题。点击「检查」，同意条款与条件后即可正常使用。

2. 提示「您的账户已在 App Store 和 iTunes 中被禁用」

通常是因为设备上仍保留着之前下载应用所用的旧账号记录。处理方式：先卸载该应用，退出当前账号，重新登录本账号后再下载。

3. 登录后搜索不到目标应用

先确认账号已成功登录（App Store 右上角头像处应显示该账号）。若已登录仍搜不到，多为缓存问题：关闭 App Store 后台进程重新打开，或切换输入法后重新搜索。

4. 提示密码错误

请确认复制时没有带入多余空格，尤其注意首尾字符。共享账号的密码会定期轮换，若持续失败请返回获取页刷新取用最新账号。

5. 提示「Apple ID 已锁定」或要求双重认证

共享账号被多人同时使用时容易出现该提示，属于苹果风控的正常反应。解决办法是更换账号，返回获取页取用新的可用账号即可。
